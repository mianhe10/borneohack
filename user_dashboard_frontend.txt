================================================================
BIZBUDDY — USER (MSME) DASHBOARD FRONTEND
Files: public/dashboard.html + public/app.js + public/style.css
================================================================

----------------------------------------------------------------
OVERVIEW
----------------------------------------------------------------
Single-page PWA. User logs in with WhatsApp phone number.
Reads from Firestore collection: users/{phone}
Dark mode default. Light mode toggle. EN/BM bilingual.
Installable (Add to Home Screen banner).

----------------------------------------------------------------
AUTH FLOW
----------------------------------------------------------------
1. Page loads → 3-second loading screen (BizBuddy wordmark + spinner)
2. Login screen appears:
   - Logo (icons/main-logo.png)
   - Tagline: "Financial Identity for Every Entrepreneur"
   - Input: WhatsApp number (with country code, e.g. 60123456789)
   - Button: "Access Dashboard ->"
3. On submit:
   - Firestore lookup: users/{phone}
   - If not found → error: "No account found. Please register via WhatsApp first."
   - If found → load dashboard

----------------------------------------------------------------
TOP NAV
----------------------------------------------------------------
- Left: horizontal-logo.png (32px height)
- Right:
  - User badge (owner_name or business_name)
  - Last updated timestamp
  - ☰ Hamburger → opens Nav Drawer

NAV DRAWER (slides in from right):
  - User name + business name
  - ↻ Refresh Data
  - ☀️/🌙 Switch theme
  - 🌐 Toggle language (EN ↔ BM)
  - 🏠 Back to Home
  - ⏻ Logout

----------------------------------------------------------------
PULL TO REFRESH
----------------------------------------------------------------
Pull down when scrolled to top → refresh indicator → re-fetch Firestore → re-render dashboard

----------------------------------------------------------------
PRE-QUALIFICATION MODAL  (opens on "Request Loan Assessment")
----------------------------------------------------------------
Summary grid:
  - Credit Score: N/100 (green)
  - Total Revenue: cur+amount
  - Transactions: N
  - Verified Sales: N% (photo receipts)

Data shared with bank:
  ✅ Business name & owner name
  ✅ Credit score & breakdown
  ✅ Revenue history & verification rate
  ✅ BizBuddy certificate ID

"Send to Partner Bank via WhatsApp" button → opens wa.me link
with pre-filled message containing all the above data.

Note: "Data protected under PDPA Malaysia. Bank contacts within 2-3 days."

----------------------------------------------------------------
FIRESTORE DATA READ
----------------------------------------------------------------
Collection: users/{phone}
Fields used:
  owner_name, business_name, product, country, user_state
  credit_score, score_date, score_breakdown, score_history
  sales[]  → {date, amount, item, source}
  expenses[]
  has_bank_account, has_ssm
  bank_verified, ssm_verified
  monthly_revenue, biz_age
  language

----------------------------------------------------------------
STATE / SETTINGS (localStorage)

  nc-theme  → 'light' | 'dark' (default dark)
  nc-lang   → 'en' | 'bm' (default en)

----------------------------------------------------------------
PWA FEATURES
----------------------------------------------------------------
- manifest.json linked
- Service Worker registered (sw.js)
  → SW update banner appears when new version available
- "Add to Home Screen" install banner (beforeinstallprompt)
- Pull-to-refresh (touchstart/touchmove/touchend, threshold 40px)

----------------------------------------------------------------
TECH STACK
----------------------------------------------------------------
- Firebase JS SDK v10.7.1 (ESM, from gstatic CDN)
- Chart.js 4.4.0 (from jsdelivr CDN)
- Fonts: Syne (headings, 400/600/700/800) + DM Sans (body)
- No build step — plain HTML/JS/CSS
- XSS: esc() function sanitizes all Firestore data before innerHTML

----------------------------------------------------------------
KNOWN ISSUES / GAPS
----------------------------------------------------------------
- LOAN_CATALOG in app.js is a static local const (not from Firestore)
  → diverges from loan_products Firestore collection used by bot
  → should ideally read from same source

- Loan program shown in "Available Loan Programs" section uses
  min_score filter against user.credit_score only
  (buildLoanRecommendations fn in app.js)

- bank.html shares same app.js — bank view code is also in this file
  (window.__BANK_PAGE__ flag separates them, but both loaded)
